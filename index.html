AUTONOMOUS TARGET INTERCEPTION

HUNTER

FIND · PREDICT · HUNT

An autonomous pursuit system designed to locate, predict and intercept a moving target in a simulated environment using intelligent navigation and real-time control.

Explore Missions Run the Simulator
01 / Missions

Three stages of pursuit.

HUNTER progressively combines localization, prediction, navigation and interception to solve increasingly complex autonomous pursuit scenarios.

MISSION 01

FIND

Locate and reach a stationary Runner while navigating through a static obstacle environment.

A* Path Planning Obstacle Avoidance
MISSION 02

PREDICT

Estimate the future position of a moving Runner from imperfect and delayed observations.

Velocity Estimation Prediction Interception
MISSION 03

HUNT

Combine prediction and obstacle-aware navigation to autonomously intercept a moving Runner.

Prediction A* Replanning
02 / Architecture

Sense. Predict. Navigate. Intercept.

The controller continuously processes the current Hunter state and Runner observations to determine the next control command.

  • Receive Hunter and Runner observations
  • Estimate target motion from measurements
  • Predict a future interception position
  • Generate an obstacle-aware path
  • Replan as the target moves
  • Execute velocity and angular commands
03 / Control Loop

Autonomous control pipeline.

Each control cycle updates the internal state and determines the next action of the Hunter.

STEP 01

Observe

Read the latest sensor and target observations.

STEP 02

Predict

Estimate target velocity and future position.

STEP 03

Plan

Calculate an efficient collision-free route.

STEP 04

Hunt

Execute the control command and repeat.
